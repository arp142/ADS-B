Technical Overview

ADS-B (Automatic Dependent Surveillance-Broadcast)

차세대 지능형 항공교통 감시 기술의 개념, 작동 메커니즘, 주요 기능 및 항공 데이터 규격 가이드

1. ADS-B 란? (개념 및 정의)

ADS-B (방송형 자동종속감시)는 항공기가 위성항법시스템(GNSS/GPS)을 통해 자체 계산한 위치, 고도, 속도 등의 정밀 비행 데이터를 지상 관제소 및 주변 타 항공기에 매초 주기로 자동 방송(Broadcast)하는 차세대 디지털 감시 시스템입니다.

  • Automatic (자동): 조종사나 지상 관제사의 별도 개입 없이 자동 연속 작동
  • Dependent (종속): 항공기 자체 GPS/INS 탑재 장비의 데이터에 종속
  • Surveillance (감시): 관제용 위치, 고도, 편명, 속도 정보 제공
  • Broadcast (방송): 수신 장비를 갖춘 모든 지상/공중 노드에 무선 전송

2. 작동 메커니즘 및 동작 원리

위치 측정 (GNSS Satellite)

GPS/GNSS 위성 신호를 받아 항공기의 정확한 3차원 공간 좌표 계산

ADS-B Out (송신 모듈)

1090 MHz Extended Squitter (ES) 주파수로 비행 항적 데이터 무선 방출

ADS-B In (수신 모듈)

지상 수신기 및 인근 항공기가 신호를 수신하여 관제 모니터링 화면에 시각화

403 에러 원인 및 해결 방법
  1. 403 Access Blocked 에러 원인: OpenStreetMap 공식 무료 서버는 웹뷰/iFrame 환경 요청을 자동 차단합니다.
  2. 기본 타일 자동 적용: 차단 제한이 없는 CartoDB Voyager를 기본 타일로 설정하여 별도 Key 없이 즉시 사용 가능합니다.
  3. API Key 사용 방법: 브이월드(vworld.kr)나 MapTiler에서 API Key를 구하신 경우, 위 드롭다운 선택 후 Key를 입력하면 해당 정밀 지도로 전환됩니다.
